# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct for everyone taking part in issues, pull requests and discussions.

In short: be respectful and welcoming, value different experience levels and
viewpoints, give and accept constructive feedback. Harassment, insulting comments and
personal attacks are not tolerated.

## Reporting

Please report unacceptable behavior confidentially via the contact options on the
[maintainer's GitHub profile](https://github.com/Maherd18). All reports will be
reviewed and handled confidentially.
